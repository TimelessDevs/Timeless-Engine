# Timeless Engine — Support & Bug Reporting

Welcome to the official support page! If you encountered a glitch, a crash, or have a question about the engine, please follow the guidelines below before asking for help.

---

> [!TIP]
> **Check your versions first!**
> Before reporting any issues, make sure you are using the latest version of the engine and compatible Haxe libraries. 

---

## How to Report a Bug

If the engine crashed or a feature is broken, we want to know about it! 

> [!CAUTION]
> **Do not spam the main page.**
> Please check the **[Closed Issues](https://github.com/therealmerlow-hub/Timeless-Engine/issues?q=is%3Aissue%20state%3Aclosed)** tab first. Someone might have already found and fixed your exact bug!

###  When opening a new bug report, please include:
1. **Crash Log:** Copy and paste the error trace from your command line / terminal.
2. **Steps to Reproduce:** Explain exactly what you pressed or what song you loaded to make the game crash.
3. **Your Platform:** Let us know if you are playing on **Windows**, **Android** or **IOS**.
